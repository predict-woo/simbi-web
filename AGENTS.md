## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Project

Landing page + docs for Simbi (open-source macOS notetaking app), deployed at
https://getsimbi.app as a Cloudflare static-assets Worker.

- Package manager: pnpm (`pnpm dev`, `pnpm build`, `pnpm deploy`)
- Landing page: `src/pages/index.astro` (custom page, no Starlight chrome)
- Docs: markdown in `src/content/docs/docs/` → served at `/docs/*`;
  sidebar autogenerated, ordered by `sidebar.order` frontmatter
- Deploy: `pnpm deploy` (astro build + wrangler deploy); custom domains
  getsimbi.app and www.getsimbi.app are configured in wrangler.jsonc
