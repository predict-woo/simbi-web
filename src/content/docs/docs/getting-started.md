## Requirements

- Apple silicon Mac
- macOS 14.0 or later. macOS 26 is recommended. System-audio capture requires
  macOS 14.4 or later.
- The ChatGPT app installed and signed in

## Install

Download the latest Apple silicon `.dmg` from
[download.getsimbi.app/darwin-arm64](https://download.getsimbi.app/darwin-arm64)
and drag Simbi to your Applications folder.

## Record your first note

1. Open Simbi and grant microphone access when prompted.
2. Create a new note and press record.
3. Speak: the live transcript appears as you go.
